# Formül Bul - Eğitim Asistanı Mobil Uygulaması

Öğrencilerin akademik formüllere ve konu özetlerine anında ulaşabilmesi, aynı zamanda çalışma sürelerini verimli yönetebilmesi için tasarlanmış bir mobil eğitim asistanıdır.

## 🚀 Kullanılan Teknolojiler
* **Platform:** iOS & Android (Cross-Platform)
* **Çerçeve:** React Native

## 📌 Temel Özellikler
* Kategori bazlı akademik formül kütüphanesi
* Detaylı konu özetleri
* Öğrenciler için entegre odaklanma sayacı (Timer)
